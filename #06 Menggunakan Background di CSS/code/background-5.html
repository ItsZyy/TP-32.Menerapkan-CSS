Belajar background di css

CSS memberikan banyak cara untuk mengatur tampilan latar belakang sebuah elemen. Kita bisa menggunakan warna solid, gradasi, bahkan gambar sebagai background. Dengan begitu, sebuah halaman web akan terlihat lebih menarik dan tidak monoton. Pada latihan ini, saya mencoba menambahkan gambar sebagai background pada tag article dan memberi sedikit efek agar teks tetap nyaman dibaca.
